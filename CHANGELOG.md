# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-14

### Added
- **Initial Project Scaffolding**: Created `plcafe-client` (Expo) and `plcafe-admin` (Next.js).
- **Core UI Components (Client)**:
    - Main menu with 'Fast Track' section.
    - Cart screen with packaging options (carrier/box).
    - Payment screen with Pl-Money recharge and barcode UI.
    - Pickup digital name tag with giant fonts.
- **Core UI Components (Admin)**:
    - 3-split layout dashboard (Queue, Detail, Control Bar).
    - Color-coded order state management.
    - Peak time mode and batch completion controls.
- **Infrastructure**:
    - Tailwind CSS v3 integration for both apps.
    - Zustand for state management.
    - Firebase integration (placeholders).
- **Automation**:
    - GitHub repository linking and initial push.
    - CI/CD automation rules established.
